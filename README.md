# 🧮 Dark Age Calculator

A sleek, **modern web app** that calculates your exact age in **years, months, days, hours, minutes, and seconds** — all wrapped in a **beautiful extreme dark mode** UI.

🌐 **Live Demo:** [Calculate Age](https://mohitscodiclab.github.io/Birthday-Calculator/)

---

## 🚀 Features

✅ Simple and intuitive interface
✅ Extreme dark mode for low-light comfort
✅ Real-time age calculation
✅ Includes **total months, weeks, days, hours, minutes, and seconds**
✅ Fully responsive — works on mobile and desktop
✅ Built with **pure HTML, CSS, and JavaScript**
✅ Includes a **Reset button** to calculate again easily
✅ **Favicon and footer with social links** (GitHub + WhatsApp)

---

## 🧠 Technologies Used

* **HTML5** for structure
* **CSS3** for extreme dark theme and glowing effects
* **JavaScript (ES6)** for dynamic age calculations
